## 📖 What is this?

**ROB-RUN-Aim-WH-Cheats** is a focused cheat package built around three things: aim control, full map vision, and item duplication.

The aim module is tunable rather than automatic — you set the FOV cone, the smoothing curve, the bone priority and the trigger key, so the crosshair moves the way you expect instead of snapping wildly. The wallhack and ESP layer shows boxes, skeletons, health and names through geometry, which turns every corner into information. The dupe tool sits alongside them for cloning stackable inventory in the modes that allow it.

Everything runs externally through memory reading. The game files stay untouched, and the whole suite unloads the moment you close the overlay.

**Q: Aim keeps overshooting — what should I change?**

**Q: The wallhack draws enemies but not items.**
A: Item filtering is a separate toggle in the ESP section — enable it independently of the player filter.

**Q: Dupe tool does nothing.**
A: It needs a stackable item in an open inventory screen. Close the overlay before triggering it, and keep the inventory still.

**Q: Why does the overlay not show up?**
A: Almost always exclusive fullscreen. Switch the game to Borderless.

**Q: How do I uninstall?**
A: Close the overlay, delete the folder. Nothing is written to the system.
